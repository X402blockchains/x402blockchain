# Facilitator directory FAQ

## Where can I find all listings?

Open the [public facilitator directory](README.md). You do not need a GitHub account to read public listings. The account Repositories tab shows repositories, not individual facilitators.

## How do I apply?

Use the [facilitator application form](https://github.com/X402blockchains/x402blockchain/issues/new?template=facilitator.yml). Sign in to submit. Include your official website, logo, public endpoint, mainnet chain identifiers, supported assets and settlement evidence. Read the [listing guide](../docs/LISTING-GUIDE.md) before submitting.

## Does listing mean approval on every chain?

No. Website inclusion and a reviewed approval are separate. Check the linked application for the exact approved network and outstanding verification. A listing is not a security audit.

## Which wallet should a facilitator provide?

Identify the public transaction sender or settlement operator separately from a seller payment recipient. Supply successful transaction hashes for each requested chain. A payment received by a seller alone does not establish who facilitated it. Never publish private keys or API secrets.

## How can I correct a listing?

Open an issue with the facilitator profile URL, the field to correct, its proposed replacement and public evidence. Link an existing application instead of submitting duplicates.

## Will a merged proposal update the website immediately?

No. Maintainer review, indexing and deployment are separate manual steps. The Markdown directory is a maintained snapshot, not an automatic synchronization job.
