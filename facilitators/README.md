## Apply or update a listing

[Submit a facilitator application](https://github.com/X402blockchains/x402blockchain/issues/new?template=facilitator.yml) with your name, website, logo, endpoint documentation, supported mainnet chain IDs, assets, public signer/settlement addresses, and settlement evidence. Never include private keys or API secrets.

For corrections, open an issue with the profile URL and supporting public documentation. Maintainers review submissions manually. See the [listing guide](../docs/LISTING-GUIDE.md).
